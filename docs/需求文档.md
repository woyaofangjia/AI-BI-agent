# 需求文档（轻量版）· 销售数据智能查询 Agent

- 版本：v1.0（2026-10-19）
- 状态：核心功能已实现并通过验收，F7/F8 为下一迭代项
- 完整背景见 [产品方案.md](产品方案.md)，验收实测见 [测试记录.md](测试记录.md)

## 功能清单

| 编号 | 功能 | 优先级 | 验收标准 | 状态 |
|------|------|--------|----------|------|
| F1 | 中文自然语言查询（NL → SQL → 结果） | P0 | 输入"TikTok上个月卖了多少钱"，返回正确 SQL 与结果（实测返回 1,073,966.76 元，与真值一致） | ✅ |
| F2 | LLM 不可用兜底 | P0 | 无 Key/断网时，常见查询仍返回结果（实测断 Key 下 Q1/Q3/Q4/Q7 结果与真值一致，耗时 <0.1s） | ✅ |
| F3 | SQL 安全校验 | P0 | 仅放行 SELECT，拒绝 INSERT/UPDATE/DELETE/DROP 等写操作 | ✅ |
| F4 | 品类/渠道字段校正 | P1 | "Blind Box"等品类词不被误判为渠道；问题含"品类"而 SQL 按 channel 分组时自动纠正为 category | ✅ |
| F5 | 图表 + 表格展示 | P1 | 单值结果渲染大数字；分组/趋势结果同时渲染 ECharts（日期折线、分类柱状）与明细表 | ✅ |
| F6 | 相对时间解析 | P1 | "上个月/六月/最近一个月"等映射为正确日期区间（时间锚点注入 prompt），实测时间类问句全部命中 | ✅ |
| F7 | 兜底规则支持时间过滤 | P2 | 断 Key 时"上个月各品类销售额对比"仍按 5 月过滤返回（当前返回全期数据，见测试记录改进项） | ⬜ |
| F8 | 指标词典（派生指标映射） | P2 | "转化率"稳定映射为 SUM(orders)/SUM(traffic)，"流量"默认 SUM 聚合（当前 LLM 自由发挥导致 2 条失败，见测试记录） | ⬜ |

## 非目标（本期不做）

- 多表 join、跨库查询（当前单表 sales）
- 任何写操作（INSERT/UPDATE/DELETE）
- 登录与权限体系、多轮对话式追问
- 数据的实时同步（当前为 CSV 定期导入）
